# همزبان · Hamzaban

**یک حافظهٔ مشترک برای همهٔ عامل‌های هوش مصنوعی تو. محلی، متن ساده، مال خودت.**

Claude Code، Codex، ChatGPT، Gemini و بقیه هرکدام به شیوهٔ خودشان یاد می‌گیرند و هیچ‌کدام نمی‌داند دیگری چه کرده است.
همزبان قواعد، تصمیم‌ها، حقیقت‌ها و وضعیت پروژه‌هایت را در یک پوشه از فایل‌های Markdown روی کامپیوتر خودت نگه می‌دارد و برای هر عامل
به «گویش» خودش می‌نویسد. به هر چت هم یک **تگ** ثابت می‌دهد؛ پس چتی که وسط کار قطع شد (سقف مصرف تمام شد، پنجره بسته شد) گم نمی‌شود:
در هر عاملی بگو «ادامه بده از CX-7K3QF».

سرور، حساب کاربری و کد شبکه ندارد. فقط کتابخانهٔ استاندارد Python. همه‌چیز در پوشه‌ای است که خودت می‌خوانی، ویرایش می‌کنی و هر وقت خواستی پاک می‌کنی.

## چه کار می‌کند

- **دفترچهٔ مشترک به زبان مشترک**: قواعد ثابت تو، حقیقت‌های تأییدشده، تصمیم‌ها و وضعیت پروژه‌ها در «Vault» (پوشهٔ سازگار با Obsidian؛ خود Obsidian لازم نیست) نگه داشته می‌شود و برای Claude Code، Codex، Gemini، ChatGPT، Cursor، Copilot و چند قالب API با گویش خودشان نوشته می‌شود. عامل تازه یعنی یک فایل JSON ده‌خطی.
- **تگ برای هر چت و هر موضوع**: `CC-7K3QF` یک چت است و `CC-7K3QF/T3` موضوع سومِ داخلش. تگ‌ها از لاگ خودِ عامل‌ها (Claude Code، Codex، Chat On Steroids) خوانده می‌شوند.
- **تشخیص قطع‌شدن**: می‌خواند چت چطور تمام شده. نوبتی که با «You've hit your usage limit … try again at 2:32 AM» تمام شد «قطع‌شده» است و ساعت برگشتن توکن هم کنارش نوشته می‌شود. چتی که فقط یک خطای گذرا داشت و ادامه پیدا کرد قطع‌شده حساب نمی‌شود.
- **ادامه در هر عامل**: ابزار `memory_handoff` (MCP) یا مهارت `hamzaban-continue` تگ را به یک متن ادامه تبدیل می‌کند: چرا قطع شد، موضوع‌ها، آخرین درخواست و پاسخ، فایل‌هایی که عوض شد.
- **بکاپ قابل‌انتقال از هر پروژه یا چت**: دستور `python .ai-memory/hamzaban/cli.py continuity write --dir <پروژه>` پوشهٔ `project-continuity/` می‌سازد (README، قواعد تو کلمه‌به‌کلمه، زمینه، گزارش تاریخ‌دار، تصمیم‌ها، گزارش تست، سؤال‌های باز) که هر جمله‌اش برچسب مدرک دارد (`CONFIRMED`، `INFERRED`، `UNKNOWN` ...). عامل بعدی یا کامپیوتر دیگر می‌تواند از همان‌جا ادامه بدهد. مهارت `hamzaban-continuity` بخش‌هایی را که به نگاه‌کردن به کد نیاز دارند به عامل می‌سپارد، و `parity` بررسی می‌کند فایل‌های دستور عامل‌ها (`CLAUDE.md`، `AGENTS.md`، `GEMINI.md`) همگی قواعد تو را دارند. جزئیات: [docs/continuity.md](docs/continuity.md).
- **حافظهٔ داخلی خودِ عامل‌ها هم ترجمه می‌شود**: یادداشت‌هایی که Claude Code برای خودش نگه می‌دارد و حافظه‌هایی که Codex استخراج می‌کند به‌صورت پیشنهاد در `30-Pending` می‌آیند. تا تأیید نکنی هیچ‌چیز «حقیقت» نمی‌شود.
- **مهارت‌های مشترک**: مهارتی که در یک عامل نصب کنی به بقیه کپی می‌شود؛ هرگز چیزی پاک یا جایگزین نمی‌شود.
- **اتاق کنترل**: یک صفحهٔ HTML آفلاین با چت‌های فعال، چت‌های قطع‌شده (با دکمهٔ کپی دستور ادامه)، جدول مهارت‌ها و مسیر جریان حافظه. روی ویندوز مثل یک برنامه نصب می‌شود: آیکون، ورودی منوی Start، شورتکات دسکتاپ و پنجرهٔ مخصوص خودش. روی هر چت دکمهٔ «کجاست؟» هست که می‌گوید چت در کدام برنامه بوده و کدام بخشِ آن است و برنامه، فایل یا پوشه را برایت باز می‌کند (جزئیات: [docs/app.md](docs/app.md)).

محدودیت‌ها (صادقانه): این **انتقال متن** است، نه وضعیت پنهان مدل. متن ادامه از لاگ استخراج می‌شود و تأییدنشده است، پس عاملِ گیرنده باید فایل‌های واقعی را دوباره بررسی کند. تقسیم موضوع‌ها حدسی (heuristic) است. چت‌های وب (claude.ai، ChatGPT، Gemini) لاگ محلی ندارند و با «بلوک پایان چت» وارد می‌شوند. شورتکات‌ها، پنجرهٔ برنامه و دکمه‌هایی که برنامه یا فایل باز می‌کنند فعلاً فقط روی ویندوزند و فقط Codex لینکی دارد که یک چتِ مشخص را باز کند. رابط اتاق کنترل فارسی (راست‌به‌چپ) است.

## نصب

**Python ۳٫۱۰ یا جدیدتر** لازم است ([python.org](https://www.python.org/downloads/)؛ روی ویندوز تیک *Add python.exe to PATH* را بزن).

**ویندوز** (هدف اصلی): پروژه را دانلود و از حالت زیپ خارج کن (دکمهٔ سبز **Code** ← *Download ZIP*) و روی **`INSTALL.cmd`** دوبار کلیک کن. می‌پرسد Vault کجا باشد و پیش از هر تغییر بیرون از آن اجازه می‌گیرد.

**macOS و Linux** (آزمایشی): `./install.sh`

**از ترمینال**

ویندوز (PowerShell):

```powershell
git clone https://github.com/mmahdighafoori10/hamzaban.git; cd hamzaban; python install.py
```

بدون git (PowerShell):

```powershell
Invoke-WebRequest https://github.com/mmahdighafoori10/hamzaban/archive/refs/heads/main.zip -OutFile hamzaban.zip; Expand-Archive hamzaban.zip -DestinationPath .; cd hamzaban-main; python install.py
```

macOS و Linux:

```bash
git clone https://github.com/mmahdighafoori10/hamzaban.git && cd hamzaban && python3 install.py
```

**نصب با یک دستیار** (Codex، Claude Code و…): این متن را در یک چت تازه بچسبان.

```text
همزبان را از https://github.com/mmahdighafoori10/hamzaban برایم نصب کن. مخزن را clone کن، فایل AGENTS.md آن را بخوان و طبقش جلو برو: اول اجرای آزمایشی (dry run) را نشانم بده، بپرس Vault کجا باشد و کدام مرحله‌ها را می‌خواهم، و فقط بعد از آن نصب کن.
```

فایل [AGENTS.md](AGENTS.md) به دستیار می‌گوید چطور: اول اجرای آزمایشی، بعد پاسخ‌های تو، و در آخر بررسی سلامت. دستیار برای نوشتن بیرون از پوشهٔ خودش اجازه می‌خواهد؛ این طبیعی است.

گزینه‌های مفید: `python install.py --dry-run` (فقط نشان بده، چیزی را عوض نکن) · `--vault مسیر` · `--yes` · `--skip hooks,schedule` · `--doctor` · `--uninstall` (کار پس‌زمینه، هوک‌ها و ثبت MCP را برمی‌دارد؛ یادداشت‌هایت دست نمی‌خورد).

هر تغییر بیرون از Vault پیش از انجام پشتیبان می‌گیرد و در `<Vault>/.ai-memory/logs/install.log` ثبت می‌شود.

روی ویندوز نصب‌کننده (با اجازهٔ تو) یک ورودی **Hamzaban همزبان** در منوی Start و یک شورتکات با آیکون همزبان روی دسکتاپ می‌گذارد و لینک `hamzaban:` را برای همین کاربر ثبت می‌کند؛ `--uninstall` همه را برمی‌دارد. جزئیات و محدودیت‌ها: [docs/app.md](docs/app.md).

## استفاده

- در چت تازهٔ Claude Code یا Codex بگو «ادامه بده از چت قبلی» یا «ادامه بده از CX-7K3QF».
- اتاق کنترل: روی ویندوز آیکون **Hamzaban همزبان** روی دسکتاپ یا در منوی Start؛ و در هر سیستمی `00-Dashboard/control-room.html` (روی ویندوز `CONTROL-ROOM.cmd` در پوشهٔ `.ai-memory`).
- پیشنهادها: `python .ai-memory/pending.py list` و سپس `approve <id>` یا `reject <id>`.
- قابل‌انتقال‌کردن یک کار یا چت: به عامل بگو «پکیج انتقال برای این پروژه بساز» یا `python .ai-memory/hamzaban/cli.py continuity write --dir <پروژه>` را اجرا کن. هماهنگی فایل‌های دستور عامل‌ها: `python .ai-memory/hamzaban/cli.py parity --dir <پروژه> --home`؛ و برای نوشتن همان قواعد در آن‌ها: `export --to <عامل> --dir <پوشه> --rules-only` (جزئیات: [docs/continuity.md](docs/continuity.md)).
- بستن چت وب: به عامل بگو «جمع‌بندی برای حافظه»؛ یک بلوک `hamzaban-close` می‌نویسد. کپی کن و `HAMZABAN-CLOSE.cmd` را اجرا کن.
- قواعدت: فایل `00-Context/Harness.md` را ویرایش کن.

## حریم خصوصی

لاگ‌های محلی عامل‌هایی را که استفاده می‌کنی می‌خواند، الگوهای رایج رمز و کلید را پنهان می‌کند و گزیده‌های کوتاه (پیام‌های تو تا ۱٬۵۰۰ نویسه، پاسخ‌ها تا ۹۰۰) را داخل Vault ذخیره می‌کند. هیچ اتصال شبکه‌ای باز نمی‌کند. پنهان‌سازی بر پایهٔ الگوست و همه‌چیز را نمی‌گیرد: رمز را در چت ننویس و Vault را در پوشه‌های همگام‌سازی ابری نامطمئن نگذار. جزئیات: [docs/privacy.md](docs/privacy.md).
